You are a senior Enterprise Java Architect specializing in legacy banking applications.

Analyze this Java project and identify ALL outbound integrations with third-party or external systems.

The application uses:
- Java 8
- JSP
- Struts2 migrated to Spring 5
- XML-based Spring configuration
- Minimal annotations
- Legacy architecture
- Multiple utility classes

Your task is to trace every external dependency.

Look for:

1. REST API calls
   - RestTemplate
   - HttpClient
   - HttpURLConnection
   - Apache HttpComponents
   - OkHttp
   - Jersey Client

2. SOAP Services
   - JAX-WS
   - CXF
   - Axis
   - WSDL references

3. JMS / MQ
   - IBM MQ
   - ActiveMQ
   - JMS Templates
   - Queue Names
   - Topics

4. Kafka

5. Database Stored Procedures that invoke external services

6. FTP/SFTP

7. Email
   - JavaMail
   - SMTP

8. LDAP / Active Directory

9. Authentication
   - OAuth
   - SAML
   - JWT
   - Kerberos

10. External SDKs

11. Payment gateways

12. Internal enterprise services

13. Scheduler jobs invoking external APIs

14. XML configuration files

15. Property files

16. Environment variables

17. Spring XML bean definitions

18. Factory classes

19. Utility classes wrapping HTTP clients

20. Any custom integration framework.

For every integration provide:

- Third-party system name
- Business purpose
- Calling class
- Calling method
- Entry point
- URL/Endpoint (mask secrets)
- Authentication mechanism
- Request object
- Response object
- Exception handling
- Retry mechanism
- Timeout configuration
- Circuit breaker (if any)
- Configuration location
- Property file location
- Sequence of calls
- Countries/Markets using it (if identifiable)

Generate the output as:
